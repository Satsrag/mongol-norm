01Execution order

01.1

This page describes the removal rules and single-pass scan of drop_redundant_zwj().Input and output are written-unit sequences.

This function only removes Zwj; the count and order of letters, Mvs、Zwnj、Nirugu are preserved.

01.2

Single-pass ZWJ removal

Step 1 of the overall plan merges consecutive ZWJs. This step starts from that merged sequence.

  1. Examine each ZWJ from left to right; remove it if a rule below allows it.
  2. After removal, keep the index in place and examine the next unit that moves into that position.
  3. Finish this step when the scan reaches the end of the sequence.

Empty input returns an empty sequence. Preserve an input of exactly [Zwj].

The current code also merges consecutive ZWJs as an input safeguard. If step 1 already merged them, this safeguard leaves the sequence unchanged.

02Removal rules

02.1

The table follows the branch order of is_redundant(); the first matching condition determines the result.

Match orderCurrent contextActionReason
1Nirugu is directly adjacent to either side of ZWJRemove ZWJNirugu already provides the connection.
2Both immediate neighbors of ZWJ are letter unitsRemove ZWJThe two letters already join naturally.
3aBoundary + Zwj + letter; the letter's far side is also a boundaryLook up INITIAL_ALONEfina → isol; remove only if the letter belongs to the table.
3bBoundary + Zwj + letter; the letter's far side remains connectedLook up INITIAL_BEFORE_LETTERmedi → init; remove only if the letter belongs to the table.
4aLetter + Zwj + boundary; the letter's far side is also a boundaryLook up FINAL_ALONEinit → isol; remove only if the letter belongs to the table.
4bLetter + Zwj + boundary; the letter's far side remains connectedLook up FINAL_AFTER_LETTERmedi → fina; remove only if the letter belongs to the table.
5The entire sequence is exactly [Zwj]KeepPreserve this representative consisting solely of a control character.
6Otherwise: both sides are boundaries, with no letter to joinRemove ZWJFor example, Mvs+Zwj+Zwnj.

At segment edges, keep ZWJ if the letter is absent from the applicable table. Equivalence reflects the reviewed decisions already encoded in the implementation.

03Four reviewed equivalence tables

These four tables apply only at segment edges: INITIAL tables require a boundary before ZWJ; FINAL tables require a boundary after ZWJ. When both immediate neighbors are letters, remove ZWJ under rule 2.

pub(crate) fn drop_redundant_zwj(shape: &[WrittenUnit]) -> Vec<WrittenUnit> {
    let mut units: Vec<WrittenUnit> = Vec::with_capacity(shape.len());
    for &unit in shape {
        if unit == Zwj && units.last() == Some(&Zwj) {
            continue;
        }
        units.push(unit);
    }
    loop {
        let before = units.len();
        let mut index = 0;
        while index < units.len() {
            if units[index] == Zwj && is_redundant(&units, index) {
                units.remove(index);
            } else {
                index += 1;
            }
        }
        if units.len() == before {
            return units;
        }
    }
}

fn is_letter(unit: WrittenUnit) -> bool {
    !unit.is_structural()
}

/// Does `unit` end a segment the way the word boundary does — an `Mvs` or a `Zwnj`?
fn is_edge(unit: WrittenUnit) -> bool {
    matches!(unit, Mvs | Zwnj)
}

/// Is the `Zwj` at `units[index]` redundant? `units` holds no repeated `Zwj`.
fn is_redundant(units: &[WrittenUnit], index: usize) -> bool {
    let prev = index.checked_sub(1).map(|i| units[i]);
    let next = units.get(index + 1).copied();
    match (prev, next) {
        (Some(Nirugu), _) | (_, Some(Nirugu)) => true,
        (Some(p), Some(n)) if is_letter(p) && is_letter(n) => true,
        (None | Some(Mvs | Zwnj), Some(n)) if is_letter(n) => {
            // An MVS or ZWNJ starts the segment like the start of the word: `n` is `init` (or
            // `isol`). The far side of `n`: another letter or a joiner keeps `n` joined onward,
            // so dropping the ZWJ turns `n:medi` into `n:init`; nothing (or an edge) leaves a
            // lone `n`, `fina` → `isol`.
            let alone = units.get(index + 2).is_none_or(|&unit| is_edge(unit));
            let same_shape = if alone {
                INITIAL_ALONE
            } else {
                INITIAL_BEFORE_LETTER
            };
            same_shape.contains(&n)
        }
        (Some(p), None | Some(Mvs | Zwnj)) if is_letter(p) => {
            // An MVS or ZWNJ ends the segment like the end of the word: `p` is `fina` (or
            // `isol`) either way.
            let alone = index < 2 || is_edge(units[index - 2]);
            let same_shape = if alone {
                FINAL_ALONE
            } else {
                FINAL_AFTER_LETTER
            };
            same_shape.contains(&p)
        }
        // A lone `Zwj` is the whole shape.
        (None, None) => false,
        // Only edges or the word boundary around it: the joiner has nothing to join.
        _ => true,
    }
}
