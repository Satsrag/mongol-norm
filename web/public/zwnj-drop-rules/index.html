ZWNJ drop rules

Single-pass removal rules, with glyphs and norm text before and after removal.

51 positional equivalences23 positive and negative examplesCommit d589ec1

This page describes one ZWNJ scan; the engine repeats complete control-processing rounds as specified in the overall policy. The norm comparisons were encoded separately at source snapshot d589ec1.

01Scope

01.1

Only evaluate and remove ZWNJ. Preserve the count and order of letters, ZWJ, Nirugu, and MVS.

The input is the current unit sequence after step 2, ZWJ drop, of the overall plan.

05Single-pass pseudocode

05.1

Proposed single-pass logic

units = copy(input)
index = 0
while index < units.length:
    if units[index] is not ZWNJ: index += 1; continue
    if this ZWNJ is the entire sequence: keep
    else if directly adjacent to MVS: remove
    else:
        candidate = remove only the current ZWNJ
        compare letter positions in units and candidate
        all positions unchanged or covered by equivalence → remove
        otherwise → keep
    after removal: keep index; after keeping: index += 1
return units
